# Omar's CURRENT TikTok editing setup (read this before suggesting any editing, caption, font, captioning or video tool)

Last updated 2026-11-03 from what Omar has told Claude. Suggest only things that BEAT or ADD to this. If a find does what he already has, say "already covered by <thing>" instead of proposing it. If you cannot tell whether something is better, say what you would need to test.

## What he runs now ("TikTok GO", launched from his TIKTOK HQ folder in Downloads on his Windows laptop)
1. Films sit-down, talking-to-camera videos in the TikTok app, saves to private videos.
2. Gets the file to the laptop (OneDrive "TikTok Inbox" folder for now, because iCloud is full; email/download also used).
3. Drops files in the Batch folder and runs **SmartEditor** (his own editor).
4. Sends results back to the phone via Phone Link and uploads them to TikTok as **drafts** (he does NOT want auto-posting; he bulk-films and pastes each caption from his phone).
5. Every caption must include `#fyppppppppppppppppppppppp #viral #fyp` plus 2 topic hashtags (TikTok allows 5).

## What the editor already does or is being built to do
- Zooms in and out at [pause] points and an opening shake (the "visual-hooks" skill).
- Building a Claude-API-planned auto-editor for full professional editing: **captions, sound effects, animations, zooms**, MrBeast-style smart cuts, dual captions and B-roll overlays.
- **Burned-in captions with the key topic words highlighted** on every video, via **SmartSub** (local, CPU-only, no accounts or API keys), being set up on the laptop. Fonts and caption styling are part of this: do not suggest a basic caption or font tool he already has.

## Constraints on any suggestion
- Free or very cheap; works on a Windows laptop with no GPU, no accounts, no per-video API cost if possible.
- Fits the flow: footage in Batch -> auto-edit -> drafts on TikTok. One click is the goal.
- Licence must allow monetised use; flag AGPL and non-commercial.
- Must not need him to post automatically.

## What would actually be an upgrade
Better caption styling or word-highlight accuracy, faster or smarter cuts, auto B-roll, sound-effect placement, a one-click phone-to-drafts hop, or anything that raises views from the ~250 plateau. Not another basic captioner.
