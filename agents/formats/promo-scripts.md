# LinkedAI / Growth Architect promo scripts

Promo video scripts use exactly the same format as Omar's TikTok scripts. Read agents/formats/tiktok-scripts.md and follow its Structure, VoicePrint pass and Self-check. The faith rules don't apply here.

Differences for promos:
- The speaker is a creator who found a useful tool (a student job hunting, a side-hustler, a small-business owner). Never the builder. Never "my app", "we built".
- Problem first, tool second. The product name lands after the hook and the context lean, usually in the Value scene, shown on screen with one specific feature doing one specific thing.
- One CTA: "link in bio" / "it's on the Chrome Web Store" / "search Growth Architect". No discount codes unless Omar gave one.
- Never invent results ("got 5 interviews", "made $2k"). Use [fill in: your real result] for the creator to fill.
- Store the same JSON fields: hookFamily, length, onScreen, scenes [{label,time,line,delivery}], hooksToTest [3], caption (one line + 5 hashtags: #fyppppppppppppppppppppppp #viral #fyp + 2 for the product niche), and script (full text with [pause] between scenes).
- Always load the voiceprint skill (and content-scripts for hooks) with the Skill tool if they are available, and run every promo script through voiceprint: register Casual → Social post, freedom "Keep the structure too, sentences only". UGC briefs get the same voiceprint pass on their example lines.
